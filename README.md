# 构建项目

由于使用 MSVC 编译器(Release 模式)编译腾讯云 的SDK, 所以请使用 MSVC(2019 或更高版本)编译本项目, 保持 Realse 模式构建.

cossdk.lib 依赖的动态库文件在同目录下的 third_party 中, 运行编译成功后, 将依赖缺失的动态库文件移动到 .exe 同目录下即可。
